Their contents are sent to this agent’s configured AI service. Switching agents keeps the chat history and loads the selected agent’s workspace.

File access and sharing
  • The agent can list and read other bounded UTF-8 files in this folder through visible tool calls, and read contents may be sent to its configured AI service.
  • IDENTITY.md, SOUL.md, USER.md, and AGENTS.md are model-read-only.
  • Visible tool calls can create or update MEMORY.md and files under memory/, and delete individual files under memory/ after reading their current version. Connecting creates MEMORY.md and memory/ when missing; chats are never saved automatically.
  • Connecting the same folder to multiple agents shares live file changes across their configured services. Parent and child folder overlaps are rejected.
  • The chat bootstrap is limited to 128 KiB, including a 64 KiB MEMORY.md limit. Other reads are limited to 256 KiB and listings to 200 matching entries.
  • Original files stay in the folder. Connections stay on this device, are excluded from settings backups, and are removed by settings imports.
